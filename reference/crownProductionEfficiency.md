# Crown production efficiency

Calculate the crown production efficiency

## Usage

``` r
crownProductionEfficiency(crown_surface_area, crown_volume)
```

## Arguments

- crown_surface_area:

  crown surface area (m^2)

- crown_volume:

  crown volume (m^3)

## Examples

``` r
crownProductionEfficiency(34,35)
#> [1] 0.9714286
```
