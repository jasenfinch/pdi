# Estimated crown volume (m^3)

Calculate estimated crown volume.

## Usage

``` r
crownVolume(r, h, l, c)
```

## Arguments

- r:

  crown radius (m)

- h:

  total height (m)

- l:

  lower crown height (m)

- c:

  crown condition (%)

## Examples

``` r
crownVolume(3,15,10,50)
#> [1] 35.34292
```
