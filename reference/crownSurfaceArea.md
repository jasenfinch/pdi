# Crown surface area (m^2)

Calculate the crown surface area

## Usage

``` r
crownSurfaceArea(r, h, l, c)
```

## Arguments

- r:

  crown radius (m)

- h:

  total height (m)

- l:

  lower crown height (m)

- c:

  crown condition (%)

## Examples

``` r
crownSurfaceArea(3,15,10,50)
#> [1] 34.90289
```
